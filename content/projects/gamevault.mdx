## What it is

GameVault is a full-stack web gaming platform I built with two teammates for a web design
course (CS 215) at the University of Regina, from January to April 2026. It has user authentication, a
game dashboard, a game history page and a dynamic User Preferences page, built with PHP,
MySQL, JavaScript and CSS.

## Technical highlights

- **AJAX preferences page.** Changes update the page in real time through DOM updates, with no page reloads.
- **Secure login.** Passwords are hashed and every database query uses prepared statements.
- **Responsive design.** The layout works across all screen sizes.
- **Validation layer.** I built the full JavaScript validation for signup, login and user preferences.
